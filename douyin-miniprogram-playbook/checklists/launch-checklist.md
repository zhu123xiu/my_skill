# Launch checklist

- [ ] Confirm the target service category supports the intended payment capability.
- [ ] Start filing and merchant onboarding early.
- [ ] Configure `production` → prod and all other `getEnvInfoSync().microapp.envType` values → dev; verify `preview` on a real device.
- [ ] Run the Node SDK pitfall checks, setup scripts, and end-to-end smoke test.
- [ ] Put customer service online during review.
- [ ] Publish the backend to prod, verify it, switch the frontend, then submit the app.
- [ ] Enable balance alerts and settle any required margin.
- [ ] Remove TODO placeholders and temporary overrides before submission.
